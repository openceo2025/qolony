# QOLONY

**アリのコロニーに学ぶ、集合知のプロジェクト管理**

[English](README.md)

QOLONY の根っこにある考え:

> 人は管理される資源ではない。
> チームは、共通のルールと互いの見える化と信頼によって自己組織化する、生きたシステムである。

アリのコロニーのように、一人ひとりは自分の持ち場で自律的に動き、それでも群れは一つの生き物のように動く。
よりよい道を見つけ、絶えず適応し、自然に仕事を分け合い、一緒に成果を届ける。

## できること

LAN 内のチームで使う、タスク・工数・進捗・評価の管理ツールです。
1タスクの担当者は1人。複数人で行う仕事はタスクを分割して表します。

| 画面 | 役割 |
|---|---|
| WBS / Gantt | タスクの木構造、日程、依存関係 |
| 巣 | 1つの画面に表と裏。**巣の外**は仕事をお菓子として、**巣の中**は組織を部屋とトンネルとして描く（下で説明） |
| My task / Today | 自分のタスクと、実績工数を記録する Start / Pause / Done のタイマー |
| Split | 表計算のような表でタスクを子に分割（コピー・貼り付け・下/右へ埋める） |
| Progress | 作業速度と進捗率のグラフ、Blue / Yellow / Red の信号 |
| Members / Ranking | 休暇・コミット率・役割と、貢献（成果量・速度・教育・指導時間）の見える化 |

## 巣（巣の外と巣の中）

「巣」のタブは、ゲームのように触る1つの画面です。ホイールで寄る・引く、ドラッグで動かす。
巣の入口をクリックすると地面の下へ潜ります。見る画面と編集する画面は分けていません。

### 巣の外 — 仕事

- **エリア**: 地面の枠で囲まれた区画。一番上のタスクごとに1つ。業務のざっくりとした区分けです。
- **お菓子**: エリアの中の仕事。大きさは、どこまで分解してよいかを表します。
  かけら（分解しない1つの仕事）・角砂糖（1階層）・包みキャンディー（2階層）・板チョコ（3階層）。
- 着手した仕事はアリが**食べていて**、完了した分はかけらが**巣へ運ばれて**欠けていきます。
  アリは巣とお菓子を行き来し、よく通る道ほど太く踏み固められます。
- 寄ると、線付きの吹き出しで中身が見え、アリの頭上に所属チームの紋章が出ます。
- 社長は地面に**チョークで方針**を書けます。社訓と同じで、みんなの目に入るだけ。ほかの何にも効きません。
- **仕事を置く**: 画面下の手持ちからお菓子をつかみ、エリアの中へポトンと落とします。
- **采配**: アリをつかんで、お菓子の上へ落とすと、その人に割り振れます。

### 巣の中 — 組織

巣の中はトンネルと部屋の断面です。**部屋 = チーム**。社長室からトンネルが枝分かれして課・係の部屋へ
つながるので、組織が何段あってもツリーとして読めます。

- 部屋をクリックすると、そのチームに所属するアリがトンネルを通って集まってきます。所属は掛け持ちできます。
- アリをつかんで部屋へ入れると所属、部屋の外（土の上）へ出すと所属を外します。
- アリをクリックするとステータスカード。役職・所属・今月運び込んだエサの量と、6か月のグラフ。
  部屋をクリックすると、チームの合計と**一人あたり**。人が多いのに成果が少ないチームも見えます。
- **食料庫**には会社全体で運び込んだエサが積もり、**育児室**には教えた時間が出ます。
  次の世代を育てるのは、コロニーの中心の仕事です。
- 遠くから見ると、部屋は扉を閉じて人数だけを出します。

数字はランキングと同じ数え方（完了した仕事の見積の合計）で、公開の決まりも同じです。
他の人の数字は上位半分だけ見え、自分の数字はいつでも、社長は全員分を見られます。

### 役職

| 役職 | 見た目 | 置けるいちばん大きなお菓子 | ほかにできること |
|---|---|---|---|
| 社長 | 葉巻 | 板チョコ | チョークで方針を書く、すべての部屋の編集、誰の役職でも決める |
| 課長 | ネクタイ | 包みキャンディー | エリアを作る。自分が主の部屋から下で部屋を掘る・所属を決める・係長を決める |
| 係長 | 黄色のヘルメット | 角砂糖 | 誰が何をやるかを決める（誰にでも割り振れる） |
| 一般 | 白いヘルメット | かけら | 未着手の仕事を自分で引き受ける |

部屋の主になれるのは課長か係長です。権限はサーバー側で確かめます。

## Windows で使う（Python や Node.js は不要）

[Releases](https://github.com/openceo2025/qolony/releases) から `qolony_windows_*.zip` をダウンロードして展開し、
中の `update_qolony_app.ps1` を実行します。アプリは `C:\qolony` に、データベースと設定は `C:\QOLONY_DATA` に置くので、
あとで更新してもデータと設定は上書きされません。詳しい手順は ZIP の中の `00_README_WINDOWS.md` にあります。
ZIP を自分で作るとき: `pwsh -File scripts/build_windows_bundle.ps1 -RuntimeEnv <conda環境名> -ZipPath qolony_windows.zip`

## はじめかた（ソースから）

必要なもの: Python 3.12、Node.js 20 以上。

```bash
cd backend
python -m pip install -r requirements.txt
cd ..
./scripts/run_backend.sh            # macOS / Linux
pwsh -File scripts/run_backend.ps1  # Windows
```

`http://localhost:8000/` を開きます。空のDBで初めて起動すると、`backend/config/settings.yaml` の
架空のメンバー全員ぶんのデモタスクが作られます。`users.members` を自分のチームに書き換えてください。
管理タブに入るときは Top Manager のパスワード（既定は `change-me`）を聞かれます。必ず変更してください。

### 開発

```bash
cd backend && python -m pytest tests -q
cd frontend && npm install && npm run check && npm test
```

`frontend/field-lab.html`（開発サーバーのみ）で、架空データの「巣の外」を確認できます。

## セキュリティ

信頼できる LAN 内での利用を前提にしています。パスワードは管理タブに入るための簡易な確認で、
API を守る認証ではありません。インターネットへ直接公開しないでください。
